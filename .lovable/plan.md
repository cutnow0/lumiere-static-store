# Lumière skincare storefront

## What I’ll build
- A polished home page with sticky logo header, editorial offer area, trust highlights, and five two-column-on-mobile product cards.
- A dedicated detail page for every product with larger imagery, description, bundle contents, price comparison, and external purchase button.
- Shared footer links for About, Contact, Shipping, and Returns, presented as concise informational panels without adding extra pages.
- A single checkout URL setting with product tracking parameters and the requested replacement comment.

## Visual direction
- Soft beige, charcoal, and restrained gold palette with Playfair Display headings and Inter body text.
- Mobile-first spacing, 12px corners, subtle shadows, and understated transitions.
- Supplied Lumière logo and product imagery used directly.

## Technical approach
- Keep the project’s supported Vite + React + Tailwind setup and use its built-in typed router for product URLs.
- Keep all storefront data and behavior client-side with no database, accounts, internal cart, or checkout.
- Add route-specific page metadata and a README covering `npm install`, `npm run dev`, `npm run build`, and static-host deployment guidance.
- Verify the build and check desktop and mobile layouts in the live preview.
